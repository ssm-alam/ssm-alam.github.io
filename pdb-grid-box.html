Method

The tool parses PDB HETATM records, groups atoms by chain/residue, excludes common water residues, and calculates the selected ligand centroid as the arithmetic mean of its atomic coordinates. Box dimensions are the ligand XYZ span plus twice the chosen padding.

Validation is essential: this is a pocket-definition utility, not a docking validator. For publication-quality docking, redock the experimental ligand and check pose RMSD before using the box for fenpyroximate. Different PDB structures and papers can legitimately use different grid centers and dimensions.
Runs entirely in the browser. PDB files are not uploaded by this page. AutoDock Vina parameters are generated as plain text for user review.
