Method

The tool parses PDB HETATM records, excludes common water residues, and lets the user choose the relevant component. The grid center is the midpoint of the selected ligand's XYZ bounding box. Box dimensions equal ligand XYZ span plus twice the selected padding. AutoGrid npts are rounded upward from physical dimensions divided by the selected spacing.

Validation: A geometry-based box is a starting point. If published or experimentally validated grid parameters exist, compare them. Redock the deposited ligand and assess pose RMSD before production docking.
