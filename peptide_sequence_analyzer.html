Algorithms currently used

  • Sequence cleaning: uppercase conversion, removal of FASTA headers, whitespace and non-sequence characters.
  • Sequence validation: checks against the 20 standard amino acids.
  • Length: number of amino-acid residues in the cleaned sequence.
  • Approximate molecular weight: sum of residue molecular masses minus H₂O for each peptide bond.
  • Approximate charge at pH 7: Henderson–Hasselbalch-style calculation using approximate pKa values for termini and ionizable side chains.
  • Hydrophobicity: percentage of residues classified as hydrophobic using the amino-acid property table included in this source.
  • Composition: residue counts, percentages and sequence positions.
  • Mutation: direct character substitution at a user-selected 1-based sequence position.
  • Secondary-structure tendency: a simple local-window heuristic using residue-specific alpha-helix, beta-sheet and turn propensity values. This is not a reproduction of PSIPRED, JPred, DSSP, AlphaFold, or another proprietary/third-party prediction implementation.
