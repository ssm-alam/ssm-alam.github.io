Method

The tool parses PDB HETATM records, groups atoms by chain/residue, excludes common water residues, and calculates the center of the selected ligand's XYZ bounding box (midpoint between minimum and maximum coordinates). Box dimensions are the ligand XYZ span plus twice the chosen padding. AutoGrid dimensions are converted to integer grid points using the selected spacing and rounded upward.

Validation is essential: this is a pocket-definition utility, not a docking validator. For publication-quality docking, redock the experimental ligand and check pose RMSD before using the box for targeted ligand. Different PDB structures and papers can legitimately use different grid centers and dimensions.
Data Sources & Disclaimer

This tool uses publicly available structural data from the RCSB Protein Data Bank (RCSB PDB). Users are encouraged to cite the original PDB entry and associated publication when using structural data obtained through this tool.

This is an independent research utility and is not affiliated with, endorsed by, or operated by RCSB PDB.

Grid-box parameters generated by this tool are geometry-based starting parameters and should be validated before production docking, for example by redocking the co-crystallized ligand and assessing pose RMSD.
